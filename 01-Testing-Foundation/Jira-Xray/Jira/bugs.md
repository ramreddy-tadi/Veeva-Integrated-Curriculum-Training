## SEQ-37 — registration passed using invalid credentials
- **Type:** Bug
- **Status:** To Do

### Description

h3. Impact

Registration can pass even when invalid credentials are used. This may allow users to complete registration incorrectly.

h3. Expected behaviour

Registration should fail when invalid credentials are entered.

h3. Actual behaviour

Registration passed using invalid credentials.

h3. Steps to reproduce

* Try to register using invalid credentials.
* Observe that registration still passes.
