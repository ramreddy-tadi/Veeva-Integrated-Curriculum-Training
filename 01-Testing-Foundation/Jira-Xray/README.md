# ShopEasy  – Agile, Jira & Xray Project

## Overview

As part of my Veeva Integrated Curriculum training, I learned the fundamentals of Software Development Life Cycle (SDLC), Agile methodology, Scrum framework, and software testing.

To gain practical experience, I worked on a sample e-commerce project called **ShopEasy** using Jira Cloud and Xray Test Management.

The project helped me understand how Agile teams plan, organize, track, and manage software development and testing activities.

## 1. Concepts Learned

### Software Development Life Cycle (SDLC)

Learned the different phases of SDLC and how software moves from requirements to deployment and maintenance.

- Requirement Analysis
- Planning
- System Design
- Development
- Testing
- Deployment
- Maintenance

### Agile Methodology

Understood the Agile approach to software development, including:

- Iterative and incremental development.
- Breaking requirements into smaller user stories.
- Continuous feedback and improvement.
- Collaboration between development and testing teams.
- Delivering working software in smaller increments.

### Scrum Framework

Learned how Scrum helps Agile teams organize and manage their work.

**Scrum Roles:**
- Product Owner
- Scrum Master
- Development Team

**Scrum Ceremonies:**
- Sprint Planning – Planning the work for the upcoming sprint.
- Daily Stand-up – Discussing progress, planned work, and blockers.
- Sprint Review – Demonstrating completed work.
- Sprint Retrospective – Discussing what went well and what can be improved.
- Backlog Refinement – Reviewing and prioritizing upcoming work.

**Scrum Artifacts:**
- Product Backlog
- Sprint Backlog
- Increment

## 2. Practical Implementation Using Jira

Created and worked on a sample e-commerce project named **ShopEasy** using Jira Cloud.

**Project Key:** `SEQ`

Practiced the following Jira activities:

- Created and explored a Jira project.
- Understood Jira project navigation and work items.
- Created Epics to organize major application modules.
- Created User Stories under relevant Epics.
- Defined descriptions and acceptance criteria for user stories.
- Organized and tracked project requirements.
- Explored Jira backlog and work item management.
- Understood the relationship between Epics, Stories, and other work items.

### Project Modules

The ShopEasy QA application was divided into four major modules:

1. Account and Login
2. Browse and Search
3. Cart
4. Payment and Checkout

Organized user stories under these Epics to understand how project requirements are structured in Agile development.

## 3. Xray Test Management

Explored Xray in Jira to understand how test activities are managed.

Practiced creating and managing:

- Preconditions
- Test Cases
- Test Sets
- Test Plans
- Test Executions

Also learned how test cases can be organized into test sets and test plans and how test executions help track testing progress.

Created detailed test steps, test data, and expected results for selected test cases.
